# tkinter_text_tag_formatter
Allows you to define tags that change a tk.Text's attributes. Anything from font and color changes, to positioning.

You can also define text code that are replaced during the rendering process. Like a TAB code that gets replaced by a \t escape code or just 4 spaces

# FormattedTextWriter
The "formatted_text_writer.py" file contains a program to more easily write formatted text
Just run the code, and it'll open up all the windows you need
There's a help button available to read
