# tkinter_text_tag_formatter
Allows you to define tags that change a tk.Text's attributes. Anything from font and color changes, to positioning. Here's a full list of the attributes:\
[https://www.tcl-lang.org/man/tcl8.5/TkCmd/text.htm](https://www.tcl-lang.org/man/tcl8.5/TkCmd/text.htm#M26:~:text=non%2Delided%20index.-,TAGS,-The%20first%20form)

You can also define text code that are replaced during the rendering process. Like a TAB code that gets replaced by a \t escape code or just 4 spaces
